# Тестирование API сервиса "Самокат" 🛵

Этот репозиторий содержит автоматизированные тесты API сервиса по доставке "Самокат".

Тесты покрывают следующие функции:
- Создание и удаление курьеров
- Авторизация курьеров
- Создание и отмена заказов
- Получение списка заказов

---

## 🧰 Стек технологий

- Java 17
- Maven
- REST Assured
- Allure Framework
- JUnit 4
- GitHub Desktop (для управления репозиторием)
